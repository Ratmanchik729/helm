# ◆ HELM — SSH Commander

Нативное десктоп-приложение (Qt / PySide6) для работы с серверами по SSH.

## Запуск

```bash
helm                 # после ./install.sh (ярлык есть и в меню приложений)
./helm.sh            # или напрямую из папки
```

Зависимости: `pyside6` (системный пакет) + `paramiko`, `pyte` (ставятся в `.venv` автоматически).

## Что умеет

| Раздел | Возможности |
|---|---|
| **Хосты** | профили (пароль / ключ / агент), группы, поиск, импорт `~/.ssh/config`, быстрое подключение `user@host:port` или `ssh -p 2222 root@1.2.3.4`, проверка отпечатка ключа хоста |
| **Обзор** | live-метрики: CPU, RAM, сеть с графиками, диски, аптайм, load, ОС |
| **Файлы** | две панели (локальная ⇄ сервер), drag & drop (между панелями и из системного файлового менеджера), очередь передач с прогрессом/скоростью/отменой, рекурсивные папки, переименование, удаление, chmod/chown, tar.gz/распаковка, du, перемещение перетаскиванием |
| **Терминал** | полноценный xterm-256color: truecolor, mc/vim/htop/top, альтернативный экран, скроллбэк 10k строк, выделение мышью, вкладки, сниппеты команд, Ctrl+C работает и в русской раскладке |
| **Редактор** | вкладки, подсветка (py, sh, yaml, json, nginx, ini, Dockerfile, js, go, c, sql, md, html), поиск/замена, номера строк, автоотступ, Ctrl+/ комментирование, сохранение через sudo, если нет прав |
| **Docker** | контейнеры (старт/стоп/рестарт/пауза/удаление, live CPU/RAM, shell, логи -f, inspect, top), образы (pull, run, rmi, prune), тома, сети, compose-проекты (up/down/restart/pull/логи/правка compose-файла) |
| **Процессы** | таблица с сортировкой и фильтром, автообновление, SIGTERM/SIGKILL/SIGHUP (с sudo-повтором), lsof |
| **Сервисы** | systemd: start/stop/restart/reload/enable/disable, статус, `journalctl -f`, правка unit-файла, daemon-reload |

Нужен sudo — пароль спросят один раз за сессию (если вход был по паролю, используется он же).

## Хоткеи

`Ctrl+T` новый терминал · `Ctrl+1…7` разделы · `Ctrl+Shift+C/V` копировать/вставить ·
`Ctrl+колесо` масштаб · `Shift+PgUp/PgDn` история · `Ctrl+S`/`Ctrl+F` в редакторе ·
`F2`/`Del`/`F5`/`Backspace` в файлах

## Где хранятся данные

`~/.config/helm/`: `hosts.json` — профили, `known_hosts` — доверенные ключи (плюс читается
`~/.ssh/known_hosts`), `settings.json` — настройки и сниппеты, `secrets.json` (права 0600) —
сохранённые пароли. Они только закодированы в base64, **это не шифрование**; лучше используйте ключи.

## Установка

```bash
./install.sh      # создаёт .venv, ставит зависимости, кладёт ярлык в меню
helm              # запуск
```
